# TreasureIsland

*A browser game for teaching finite automata in computer science class: students act as pirates who navigate from island to island using a boarding-card number, until they reach the treasure island. The app and this README are in German, as it's built for German-speaking classrooms.*

Browserspiel für den Informatikunterricht zur Einführung in endliche Automaten: Schülerinnen und Schüler navigieren als Piraten mit einer Bordkartennummer von Insel zu Insel, bis die Schatzinsel erreicht ist.

Basiert auf einer Idee von [Computer Science Unplugged](https://csunplugged.org/en/resources/treasure-island/).

## Ausprobieren

👉 <https://treasureisland.unterrichtsportal.org>

Das Spiel funktioniert direkt ohne Admin-Zugang – eine Bordkarte lässt sich selbst erstellen. Die Bedienung wird auf der Seite selbst über den „Info"-Button erklärt.

## Admin-Zugang

Mit Admin-Zugang (Passwort auf Anfrage) lässt sich der Unterricht zusätzlich steuern:

- Bordkarten und Clients verwalten bzw. löschen, oder alles auf den Standardzustand zurücksetzen
- Inseltyp einzelner Clients manuell setzen
- Optionen an-/ausschalten (z. B. Bordkartenerzeugung oder Inselwechsel im Client), inklusive Schnellvorlage für vorgefertigte Bordkarten bei mehreren Rechnern
- aktive Piraten und ihren Fortschritt einsehen

## Lizenz
